# إدارة مدونة UGC Arabie — HTML ثابت

المدونة الآن مبنية بنفس طريقة Viva Media Creative: **مجلد مستقل لكل مقال، بداخله ملف `index.html` كامل قابل للتعديل على GitHub**.

## روابط المصدر

- صفحة المدونة: [`blog/index.html`](../blog/index.html)
- صفحات المقالات: `blog/<المسار-العربي>/index.html` — 6 مقالات منشورة.
- بيانات البطاقات والتصنيفات: [`blog/manifest.json`](../blog/manifest.json)
- تنسيق المقالات الإضافي: [`blog/static.css`](../blog/static.css)
- بحث وتصنيفات المدونة: [`blog/site.js`](../blog/site.js)
- تنسيق العلامة البصرية العام: [`src/styles.css`](../src/styles.css)؛ يتم نسخه أثناء البناء إلى `dist/blog/site.css`.

## تعديل مقال منشور

1. افتح `blog/<المسار-العربي>/index.html` داخل GitHub، واضغط Edit.
2. عدّل النص داخل HTML مباشرة، مع الحفاظ على `<h1>` واحد والعناوين `<h2>` وأجوبتها وفقرات المقال الأصلية.
3. عند تغيير العنوان أو الوصف، حدث أيضاً `<title>` و`meta description` و`og:title` و`og:description` وبيانات `BlogPosting` المرتبطة به.
4. عدّل `dateModified` و`article:modified_time` فقط عند تعديل جوهري حقيقي للمقال. لا تغيّر تاريخ النشر الأصلي.
5. إذا عدّلت عنوان البطاقة أو وصفها أو تاريخها، حدّث بيانات نفس المقال في `blog/manifest.json` لتظل بطاقات الموقع متطابقة مع المقال.
6. احتفظ بمسار المجلد العربي ورابط `canonical` كما هو، ولا تغيّره إلا مع خطة توجيه SEO واضحة.
7. احفظ التعديلات على `main`. عملية GitHub Actions تبني الموقع وتتحقق من ملفات HTML والروابط وبيانات SEO قبل النشر.

**مهم:** لا تعدّل `dist/` لأن مخرجات البناء تُنشأ تلقائياً. ملفات HTML المعتمدة موجودة في `blog/` على فرع `main`. ولا تعدّل ملفات المقالات JavaScript القديمة؛ النصوص الكاملة لم تعد مخزنة فيها.

## الصور

كل صفحة تحتوي على مسار الصورة الأصلي `/images/blog/<filename>.webp`. ارفع WebP إلى `public/images/blog/` بالاسم المسجل في `blog/manifest.json`، ثم سيعرضه المقال تلقائياً. لا تضف وسوم `og:image` أو حقل الصورة إلى البيانات المنظمة يدوياً للصورة غير المرفوعة؛ مهمة `scripts/publish-static-blog.mjs` تضيفها فقط عندما يكون ملف الصورة موجوداً بالفعل ضمن مخرجات البناء.

## النشر وSEO

`npm run build` ينفّذ Vite، ثم ينشئ HTML الصفحات الديناميكية وخريطة الموقع عبر `scripts/generate-seo.mjs`، **وبعدها ينسخ المدونة من `blog/` مباشرة إلى `dist/blog/`** عبر `scripts/publish-static-blog.mjs`. تنصّ الاختبارات على تطابق المقال المنشور مع المصدر، مع السماح فقط بإضافة بيانات الصور الموجودة.

لا حاجة إلى JavaScript لقراءة نص المقال؛ JavaScript في `blog/site.js` يخص تصفية المقالات وفتح قائمة الهاتف فقط.

## إضافة مقال جديد

أنشئ `blog/<مسار-عربي-جديد>/index.html` بتصميم أحد المقالات الحالية، ثم سجّل بياناته داخل `blog/manifest.json`. بعد تحديث اختبار عدد المقالات وفق العدد الحقيقي، سيظهر ضمن بطاقات المدونة وخريطة الموقع. اربط المقال الجديد بمقالات ذات صلة وبصفحات خدمات المنصة، وتأكد من صحة Schema وCanonical وموعد النشر والصورة.
