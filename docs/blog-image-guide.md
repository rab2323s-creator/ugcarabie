# صور مدونة UGC Arabie

تم تجهيز المقالات الستة والبطاقات بأماكن الصور. ارفع الصور الأصلية بصيغة WebP داخل مجلد `public/images/blog/` في المستودع، وبالأسماء التالية تماماً، وسيعرضها الموقع تلقائياً عند النشر التالي.

**المقاس المفضل:** 1600 × 900 بكسل (16:9). استخدم صوراً أصلية أو صوراً مرخّصة للاستخدام التجاري، مع حفظ ملفات WebP بجودة بصرية جيدة وحجم خفيف قدر الإمكان (يفضّل أقل من 300KB إذا أمكن دون فقد ملحوظ). تجنّب صور الشركات والأشخاص الحقيقيين دون الإذن اللازم. لا تضع نصاً عربياً صغيراً داخل الصورة.

| الملف المطلوب | موضوع الصورة | المقال |
| --- | --- | --- |
| `ugc-creator-without-followers.webp` | صانع/ة محتوى يصوّر منتجاً بهاتف ضمن مساحة عمل منزلية بضوء طبيعي | كيف تصبح صانع محتوى UGC بدون متابعين |
| `ugc-portfolio-guide.webp` | هاتف يعرض فيديو عمودياً مع لوحة تنظيم نماذج الأعمال، وأدوات تصوير بسيطة | كيف تسوي بورتفوليو UGC |
| `ugc-creator-selection.webp` | فريق تسويق يراجع بورتفوليو مبدعين وفيديوهات UGC | كيف تختار صانع UGC |
| `ugc-vs-influencer-marketing.webp` | مشهد تحرير فيديو UGC مع شاشة تخطيط تعاون مؤثرين، بأسلوب تحريري موحد | الفرق بين UGC والتسويق بالمؤثرين |
| `ugc-pricing-saudi-arabia.webp` | منتج عناية بالبشرة وهاتف يصوّر فيديو عمودياً مع تفاصيل إنتاج نظيفة | أسعار UGC في السعودية |
| `ugc-opportunities-uae-egypt.webp` | مشهد يجمع منتجاً تقنياً وتجربة تصوير مقهى، بشكل متوازن وغير مزدحم | فرص UGC في الإمارات ومصر |

## طريقة الرفع

1. افتح المستودع `rab2323s-creator/ugcarabie`.
2. اذهب إلى `public/images/blog/`، وأنشئ المجلدات إذا لم تكن موجودة.
3. ارفع الملفات الستة بصيغتها WebP وبالأسماء المحددة أعلاه.
4. احفظ الملفات على فرع `main` وانتظر نجاح نشر GitHub Pages.
5. ستظهر الصور مكان البطاقات التصميمية تلقائياً، وسيضيف مولّد HTML بيانات الصور إلى صفحات المقالات ووسوم Open Graph وBlogPosting عند نجاح البناء.

**ملاحظة:** لا ننشر رابطاً لصورة غير موجودة في البيانات المنظمة. قبل رفع الملفات يظهر تصميم احتياطي متناسق من دون صورة مكسورة.
